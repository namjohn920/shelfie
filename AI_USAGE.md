# AI Usage

AI tools were used as development accelerators and reviewers throughout Shelfie.

- ChatGPT supported architecture discussion, planning, debugging, experiment design,
  code and product review, and interview preparation.
- OpenAI Codex CLI supported scoped implementation, tests, refactors, audits, and
  repetitive verification.

The developer reviewed the resulting work, made the product and architecture
decisions, ran physical-device tests, inspected real detector and model outputs, and
selected the local detector and hosted reader from measured evidence. The developer
understands and remains responsible for the submitted code and documentation.

No credentials, private conversations, private working logs, prompts, token counts, or
internal tool instructions are included in this disclosure.
